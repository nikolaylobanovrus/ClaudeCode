# Обновление сайта nalog-service.online — пошагово

В архиве 4 файла. Их нужно положить на хостинг Beget поверх старых.
Ничего удалять не надо, ничего настраивать не надо.

## Шаг 1. Распакуйте архив на компьютере

Внутри увидите:

```
index.html
offer.html
policy.html
js/
   app.bc237cf3.js
ЧТО-КУДА.md   ← эта инструкция, на сайт не грузить
```

## Шаг 2. Откройте Файловый менеджер Beget

1. Зайдите в панель управления Beget: https://cp.beget.com
2. В левом меню нажмите «Файловый менеджер».
3. Откроется список папок. Найдите папку сайта: обычно она называется
   `nalog-service.online`, внутри неё папка `public_html`. Зайдите в
   `public_html`.
4. Как понять, что вы в нужном месте: в папке лежат файлы `index.html`,
   `offer.html`, `policy.html`, `favicon.ico` и папки `css`, `img`, `js`.

## Шаг 3. Загрузите три файла в корень сайта

1. Находясь в `public_html`, нажмите кнопку «Загрузить» (значок стрелки
   вверх на панели сверху) или просто перетащите файлы из папки с архивом
   в окно браузера.
2. Загрузите три файла: `index.html`, `offer.html`, `policy.html`.
3. Файловый менеджер спросит, заменить ли существующие файлы. Ответьте
   «Заменить» (или «Перезаписать»).

## Шаг 4. Загрузите один файл в папку js

1. Зайдите в папку `js` (двойной клик).
2. Там уже лежит файл `app.bc237cf3.js` и ещё один `chunk-vendors.…js`.
   Второй не трогаем.
3. Загрузите `app.bc237cf3.js` из папки `js` архива. На вопрос о замене —
   «Заменить».

## Шаг 5. Проверьте сайт

1. Откройте в браузере https://nalog-service.online
2. Нажмите Ctrl+F5 (на Mac: Cmd+Shift+R), чтобы браузер забрал новые файлы,
   а не показал сохранённые старые.
3. Что должно измениться:
   - в разделе «Цены» три тарифа: Базовый 990, Оптимальный 1 210,
     Премиум 1 540, одной высоты;
   - в подзаголовках тарифов сроки: до 3, до 2, 1 рабочий день;
   - в «Контактах» только две кнопки мессенджеров: Telegram и Max;
   - в ответах на вопросы внизу страницы нет WhatsApp и Viber;
   - https://nalog-service.online/offer.html — дата «07» сентября 2026 г.,
     в таблице внизу три тарифа.
4. Если после Ctrl+F5 всё ещё два тарифа — откройте сайт в режиме инкогнито
   (Ctrl+Shift+N). Если и там два — значит, файл `js/app.bc237cf3.js` не
   заменился, повторите шаг 4.

## Шаг 6. Напишите мне «загрузил»

Я проверю сайт со своей стороны и в тот же час включу обе кампании
«под ключ» в Директе.

## Если что-то пошло не так

Откат — те же четыре файла из папки `original` в репозитории (или скажите
мне, пришлю архив со старыми файлами). Сайт нельзя «сломать» этими файлами:
это те же страницы с исправленными текстами, серверная часть (форма заявки,
оплата) не затрагивается.
