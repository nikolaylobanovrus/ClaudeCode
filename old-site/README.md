# Старый сайт nalog-service.online — патч под «под ключ»

Сайт живёт на общем хостинге Beget, исходников нет: только собранный
Vue-бандл. Здесь лежит всё, чтобы правки были воспроизводимы:

- `original/` — файлы, снятые с сайта 07.09.2026 (только те, что меняем).
- `patch.py` — сами правки; каждая проверяет, что нашла ровно то место,
  которое ожидала. Запуск: `python3 old-site/patch.py`.
- `patched/` — результат, его и загружаем.

## Как загрузить в Beget (подробная инструкция для владельца — в ЧТО-КУДА.md внутри архива и ниже)

Панель Beget → «Файловый менеджер» → папка сайта `nalog-service.online/public_html`
(имя может отличаться, ориентир — там лежат `index.html`, `offer.html`, папка `js`).

1. Загрузить с заменой четыре файла из `patched/`:
   - `index.html` → в корень
   - `offer.html` → в корень
   - `policy.html` → в корень
   - `js/app.bc237cf3.js` → в папку `js/` (имя файла то же, заменяем)
2. Открыть `https://nalog-service.online/?nocache=1` — должно быть три
   тарифа и в контактах только Telegram и Max. Если видны два тарифа —
   кэш браузера, Ctrl+F5.

Откат: те же четыре файла из `original/`.
