# Подключение базы клиентов (Supabase) — инструкция для владельца

База нужна для кабинета оператора (`/operator`): в ней автоматически появляются
клиенты после регистрации на сайте, оператор ищет их по ID/телефону и ставит
признак «Декларация направлена» — после этого у клиента в кабинете появляется
кнопка «Оплатить».

Пока база не подключена, сайт работает как раньше (оплата видна всем).

## Шаг 1. Создать проект (~5 минут)

1. Зайдите на https://supabase.com → **Start your project** → войдите через
   GitHub или почту.
2. **New project**: любое имя (например, `nalog-service`), придумайте пароль
   базы данных (сохраните его), регион — любой европейский (например, Frankfurt).
3. Дождитесь создания проекта (~2 минуты).

## Шаг 2. Создать таблицу и функции

1. В меню слева откройте **SQL Editor** → **New query**.
2. Скопируйте туда ПОЛНОСТЬЮ содержимое файла `docs/supabase-setup.sql`
   из этого репозитория и нажмите **Run**. Должно появиться «Success».

## Шаг 3. Создать пользователя-оператора

1. Меню слева → **Authentication** → **Users** → **Add user** → **Create new user**.
2. Укажите email и пароль оператора (это логин для входа на `/operator`).
3. Поставьте галочку **Auto Confirm User** (если есть) и создайте.

## Шаг 4. Прислать ключи

1. Меню слева → **Project Settings** (шестерёнка) → **API**.
2. Скопируйте и пришлите разработчику два значения:
   - **Project URL** (вида `https://abcdefgh.supabase.co`)
   - **anon public** ключ (длинная строка; это публичный ключ, его можно
     хранить в коде сайта — доступ к данным он не даёт благодаря RLS).

## Обновление: тарифы и суммы (если база уже создана)

Если вы настраивали базу раньше (без полей тарифа/суммы) — примените миграцию:
**SQL Editor → New query** → вставьте содержимое `docs/supabase-migration-tariff.sql`
→ **Run**. Это добавит поля `tariff`, `amount` и функцию `get_payment`.

## Что получится после подключения

- Регистрация на сайте → клиент появляется в базе (ID, email, телефон),
  выбор ситуации дописывается автоматически.
- Оператор открывает `https://<сайт>/#/operator`, входит по email/паролю,
  ищет клиента по ID, телефону или email и выбирает тариф (Базовый /
  Оптимальный / Премиум) или задаёт свою сумму.
- Клиент в своём кабинете сразу видит фиксированную сумму и кнопку «Оплатить»
  (до назначения суммы — «Готовим ваши документы…»).

## Безопасность

- Анонимный ключ не открывает доступ к данным клиентов: сайт может только
  добавить запись о себе и узнать «да/нет» по числовому ID.
- Email и телефоны видит только вошедший оператор.
- Бесплатный проект Supabase «засыпает» после ~недели без обращений и сам
  просыпается при первом запросе (задержка пары секунд).
