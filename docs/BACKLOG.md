# Бэклог

## ~29.08.2026 — Переезд хостинга на Cloudflare Pages (убрать # из URL)

Зачем: hash-роутер (#/) не даёт поисковикам индексировать внутренние
страницы — весь сайт для Яндекса выглядит одной страницей. К сезону
3-НДФЛ (декабрь–апрель) нужна органика по внутренним страницам.

План:
1. Проект Cloudflare Pages из ветки `claude/react-website-wi5fnz`,
   сборка БЕЗ `VITE_HASH_ROUTER` (BrowserRouter, чистые URL).
   `public/_redirects` для SPA-fallback уже в репозитории.
2. Редиректы старых hash-адресов: скрипт на новой главной читает
   `location.hash` вида `#/путь` и делает replaceState на чистый путь —
   старые ссылки из объявлений и черновиков продолжают работать.
3. DNS: домен налог-сервис.рф → Cloudflare Pages (переключение — минуты,
   откат — обратная смена DNS).
4. После переезда: снять noindex-ограничения, расширить sitemap.xml
   внутренними страницами, обновить robots.txt, перепроверить возврат
   с ЮKassa (?order=), deep-link ?s=, ссылки-черновики ?d=.
5. Реклама: объявления менять не нужно (redirect подхватит), но после
   стабилизации можно перевести Href на чистые URL.

Напоминание поставлено триггером на 29.08.2026 (сессия Claude).
