## Чистые URL (убрать # из адресов) — план от 29.08.2026

Зачем: hash-роутер (`#/`) не даёт поисковикам индексировать внутренние
страницы — весь сайт для Яндекса выглядит одной страницей. К сезону 3-НДФЛ
(декабрь–апрель) нужна органика.

### Переезд на Cloudflare отменяется — он больше не нужен

Задача ставилась 29.07, когда сайт жил на GitHub Pages: там нет серверного
SPA-фолбэка, поэтому чистые URL требовали переезда на площадку, которая его
умеет. **18.08 сайт переехал на Beget VPS**, и там уже стоит nginx с

```
location / { try_files $uri $uri/ /index.html; }
```

Проверено на боевом 29.08: `/vychety`, `/deklaraciya/instrukciya` и даже
несуществующий путь отдают 200 и приложение. То есть **DNS менять не надо,
аккаунт Cloudflare не нужен, хостинг не трогаем вообще** — вся работа
сводится к сборке и нескольким местам в коде.

### Что реально надо сделать

**1. Переключить роутер.** Убрать `VITE_HASH_ROUTER=1` из двух мест:
`scripts/publish-dist.sh` (боевая выкладка) и `.github/workflows/deploy-pages.yml`
(резервная площадка). В `src/main.jsx` логика уже двухрежимная.

⚠️ Резервная площадка на GitHub Pages **обязана остаться на hash-роутере**:
там серверного фолбэка нет, чистые URL дадут 404. То есть площадки
разъедутся по режиму роутинга — это нормально, но должно быть записано,
иначе при следующем аварийном переключении DNS получим битые ссылки.

**2. Шим для старых адресов `#/путь`.** В `src/main.jsx`, до рендера: если
`location.hash` начинается на `#/`, сделать `replaceState` на чистый путь,
сохранив `search` (там живут `?order=`, `?s=`, `?d=`, `?korr=`, UTM).
Без этого ломаются: 109 объявлений Директа (все ведут на `#/deklaraciya`),
сохранённые черновики, ссылки в статьях Дзен и материалах VK, закладки.

**3. Убрать захардкоженные `#/` из кода** — четыре места:
`src/lib/draftLink.js:23,24`, `src/pages/SelfServiceKalkulyator.jsx:85`,
`src/lib/ndfl/instrukciya.js:171` (текст в PDF-инструкции),
`src/components/ChatWidget.jsx:43` (только отчётность).

**4. Пересмотреть noindex.** Сейчас индексируются 9 страниц, и набор
странный: `/registraciya` (форма регистрации) открыта, а `/deklaraciya/tarify`
и `/situaciya/*` закрыты, хотя это контент. Разобрать после переключения.

**5. sitemap.xml** — сейчас в нём одна главная (с комментарием «сайт на
hash-роутере»). Расширить реальными URL индексируемых страниц.

**6. Проверить руками после выкладки:** возврат с ЮKassa (`?order=`),
deep-link ситуации (`?s=`), ссылка-черновик (`?d=`), уточнёнка (`?korr=`),
переход из калькулятора в анкету, старая ссылка вида `#/deklaraciya/anketa`.

**7. Реклама.** Href объявлений менять не обязательно — шим их подхватит.
Когда всё устоится, перевести на чистые URL, но это перемодерация 109
объявлений, так что не в один заход с переключением.

### Риск и откат

Откат — одна строка (вернуть `VITE_HASH_ROUTER=1` в скрипт публикации) и
повторный запуск выкладки: 5 минут до сервера. DNS не трогается, поэтому
«пропасть» сайт не может.

Побочный эффект: в Метрике адреса страниц сменят вид (`/#/deklaraciya/anketa`
→ `/deklaraciya/anketa`), отчёты по страницам до и после переключения не
склеятся. Цели не затронуты — они по именам событий.
